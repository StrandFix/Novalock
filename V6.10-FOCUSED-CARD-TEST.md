# Novalock V6.10 — focused Cocoon game card recognition (device experiment)

The user explicitly wants Novalock to remain completely standalone. No
modification of Cocoon APK, no import of platform JSON, no emulator patches,
no root or ADB, and no per-game image selection.

### Architecture

1. When Cocoon is open, Android Accessibility may send focus/click/selection
   events. V6.10 reads only the focused event node, its parent, or the node
   currently exposed by Android focus APIs.
2. If Android exposes a realistic **bounded card rectangle**, Novalock takes
   one focused card screenshot while Cocoon is confirmed active and awake.
   It does NOT continuously scan HOME, other applications, or gameplay.
3. All images in the user-approved Cocoon folder are pre-indexed with compact
   pixel vectors locally. The screen rectangle is cropped in six interior
   variations, and compared against image assets. Only a distinct winner with
   high confidence can identify the game. Multiple artwork files for one
   game are treated as the same identity. System/platform icons excluded.
4. The identified game is linked only to a subsequent emulator switch within
   20 seconds (or short-late local matching of a screenshot verified from
   Cocoon); otherwise screenshots are used.
5. No OCR, ROM interception, cloud services, per-game manual selection,
   speculative full HOME matching, or scanning during sleep.

### What this does NOT prove

Compiling cannot prove that Cocoon exposes an individual card rectangle, or
that the artwork Cocoon renders is sufficiently similar to files in its
SAF folder. If events describe a fullscreen Flutter surface, the app refuses
to guess, and diagnostics show this limitation explicitly.

### How to test

- Install the V6.10 test APK. Android may require temporarily disabling and
  re-enabling Novalock Accessibility service because
  `canRetrieveWindowContent` has changed to true.
- Select **Cocoon Icon** or **Cocoon Hero**, connect the Cocoon image folder,
  tap **Refresh artwork index**; do not launch a game until status says
  `Card index ready`.
- In Cocoon, focus a game card and launch it normally. Do not change launcher
  configurations or emulator player defaults.
- Lock the device, then open Novalock settings and tap **Copy artwork matching
  diagnostics**. The useful lines are:
  - Focused-node event count and Focused-node bounds
  - Focused image index / Focused image match (winner, runner-up, scores)
  - Pending Cocoon game, Assigned title, Loaded image
  - Last emulator title / package and Decision
- If game image is missing, retain normal screenshot. Do not attempt to lower
  matching confidence without analyzing the diagnostic.

### Rollback

All changes are contained in Novalock. Cocoon and emulator applications are
untouched. Switch Cocoon image mode back to Live screenshot, or reinstall the
previous working Novalock version if the experimental build has UI trouble.
